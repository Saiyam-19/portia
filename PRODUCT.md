# Portia / Plisto

## Platform

web

## Product Purpose

Maritime assistant for exploring port tariffs, estimating charges, and comparing supported Indian ports and terminals. The application brand is Plisto; the repository is Portia.

## Evidence on Hand

README.md and the existing dashboard establish authenticated chat, streamed responses, saved history, structured follow-up forms, and two public model aliases. Backend tariff documents are static reference schedules, including historical material. Estimates require checking current authority rules.

## Capabilities and Constraints

This redesign changes the complete chat workspace: sidebar, messages, composer, and their responsive states. Preserve existing authentication, API contracts, history, calculations, citations, form continuation, and Model 1 / Model 2 aliases. Do not invent connected services or operational capabilities.

## Brand Commitments

User requests a Codex-inspired workspace with light and dark themes and permits modest visual departures when they improve the design. Keep the existing Plisto name and maritime context.

## Open Decisions

Specific commercial audience, organization features, and new backend capabilities are outside this visual refactor.

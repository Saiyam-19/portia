The language model proposes tasks, scopes and fact operations against numbered authenticated input records. The reducer checks evidence identity, prior revision, dimensional conversions, operation targets, contradictions, and source roles. A quoted evidence span alone is insufficient: numeric atoms and their units/roles must agree; reference/negated/conditional statements cannot become positive current facts. Unresolved interpretation remains an obligation. No confidence threshold, fixture identity, whole-sentence grammar or neutral-word allowlist authorizes a calculation.

Validated interpretation receipts are saved in ordinary fenced tool history. Replay verifies receipts against the authenticated input records and reducer version. Assistant prose, lookup and memory are separate evidence classes. Corrections target one fact/scope; a new call never inherits voyage facts silently. No global or cross-owner interpretation cache is introduced.

Each requested task yields a disposition: calculated, explained, excluded, not applicable, or unresolved. Rule requirements determine questions. Reviewed official rules and supplied quotations use a shared calculation/answer envelope; official source authority remains server-owned. Raw elapsed time remains independently answerable. Financial text is rendered from the bound ledger and cannot stream until the existing atomic backend completion gate accepts it.
